# comercial/benchmark/

Uma ficha por concorrente. Use `_modelo-concorrente.md` como base e salve como `nome-do-concorrente.md`.

Isso não é espionagem, é calibragem. Você precisa saber o que o cliente vê quando compara você com os outros: preço, promessa, prova e canal.

**Como usar com o Claude:**

- "monta a ficha da [empresa]" — ele pesquisa o site e as redes e preenche a ficha
- "compara minha oferta com o benchmark" — ele cruza com `comercial/oferta.md` e aponta onde você está caro, barato ou igual a todo mundo
- "o que ninguém está falando nesse mercado" — ele lê as fichas juntas e procura o espaço vago

Revise a cada trimestre. Ficha de benchmark velha mente com confiança.
