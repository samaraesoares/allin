# comercial/pesquisa-mercado/

Onde ficam as pesquisas que sustentam decisão: entrar num nicho, mudar preço, criar oferta nova, escolher canal.

Use `_modelo-pesquisa.md` como base. Um arquivo por pergunta, nomeado `AAAA-MM-pergunta.md`.

**A regra que faz a pesquisa valer:** começar pela pergunta, não pelos dados. "Vale a pena atender clínicas odontológicas?" é pesquisa. "Dados sobre odontologia" é entulho.

**Como usar com o Claude:**

- "pesquisa [nicho] pra mim" — ele levanta tamanho, players, preço praticado e dor comum, e escreve o arquivo
- "o que a gente aprendeu sobre [assunto]" — ele lê as pesquisas antigas antes de sair buscando de novo

Toda afirmação forte pede fonte e data ao lado. Sem isso, daqui a três meses ninguém sabe se aquilo ainda é verdade.
