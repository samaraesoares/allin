# conteudo/empresa/

Conteúdo que sai **no nome da empresa**, no perfil da marca.

O `/setup` renomeia esta pasta com o nome do seu negócio (`conteudo/minha-empresa/`, por exemplo).

## O que vive aqui

Método, prova, case, serviço, bastidor de entrega. O conteúdo que responde "o que essa empresa faz e por que ela é boa nisso". É o que sustenta a venda depois que a pessoa já conhece você.

Sugestão de organização:

```
empresa/
├── posts/
├── cases/         resultado de cliente, com número e autorização
└── publicados/
```

## Case de cliente

Antes de publicar case, duas checagens: o cliente autorizou por escrito, e o número que você vai mostrar é verificável. Case com número inventado destrói mais reputação do que a ausência de case.
