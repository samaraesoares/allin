# financeiro/fechamentos/

Um arquivo por mês fechado, no formato `AAAA-MM.md`. Escrito pela skill `/fechamento-mes`.

Fechamento é fotografia: depois de fechado, não se reescreve. Se um número estava errado, corrige no mês corrente e anota a correção. Histórico que muda não serve pra comparar nada.

O que cada fechamento guarda: faturado no mês, recorrente no fim do mês, quem entrou, quem saiu, comparação com a meta e a leitura do que aconteceu.
