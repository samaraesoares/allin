# Fontes da marca

Baixar do Drive e colocar os `.otf` aqui:
https://drive.google.com/drive/folders/1mkE_AU1UR_z8WUCK7TgfN5qH2pS0g589

- `kepler-std-3-cdnfonts/` -> Kepler Std (Display) - Regular, Italic, Semibold, Semibold It, Bold, Bold It
- `sf-pro-display/` -> SF Pro Display - Regular, Medium, Bold

Depois de copiar, instalar no Windows: clique direito no arquivo -> Instalar.

Sem as fontes instaladas, todo HTML gerado cai no fallback (Bodoni Moda / system-ui)
e a assinatura visual da marca se perde.
